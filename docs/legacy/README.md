# Documents de l'ancienne architecture (archives)

Ces guides décrivent le bot **avant sa reconstruction** : SDK Polymarket avec wallet et clé
privée, stratégies héritées (DipArb, smart money, arbitrage, analyse de tendance), ancien
dashboard (soldes MATIC/USDC, 4 stratégies, wallets suivis), correctifs C2–C9.

**Ils ne décrivent plus ce bot.** Le bot actuel est papier uniquement, sans wallet ni clé,
avec une seule stratégie (juste valeur sur les rounds « Up or Down 5 min ») : voir le
[`README.md`](../../README.md) à la racine, seule référence à jour.

| Fichier | Contenu d'origine |
|---|---|
| `QUICKSTART.md` | Mise en route de l'implémentation du SDK (anglais). |
| `BEGINNER_GUIDE.md` | Guide débutant complet de l'ancien bot (anglais, ~29 000 mots). |
| `README_AR.md` | Ancien README en arabe (v3.1). |
| `DASHBOARD.md` | Ancien dashboard (soldes, stratégies, wallets). |
| `CHANGES-APPLIED.md` | Correctifs C2 / C3 / C5 / C6 / C9 appliqués à l'ancien code. |

Conservés pour l'historique (le dépôt git garde de toute façon chaque version).
